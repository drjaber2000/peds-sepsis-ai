# Paediatric sepsis mortality prediction: a hands-on clinical AI course

Six Jupyter notebooks that build, evaluate and critique a mortality prediction model for children admitted with suspected sepsis. They use open data from the **2024 Pediatric Sepsis Challenge** (Uganda, 6–60 months).

The emphasis is on **clinical AI methods and pitfalls** rather than on getting the highest score: leakage, missing data, calibration, thresholds, fairness and transportability.

> ⚠️ **Educational project. Not a clinical tool.** The data is *synthetic* (generated from a real cohort), and no model here is validated for patient care. Numbers illustrate methods and should not be read as clinical conclusions.

## Lessons

| # | Notebook | Topics | Key result |
|---|---|---|---|
| P1 | [Data overview](P1_data_overview.ipynb) | Unit of analysis, outcome, coding, missingness, plausibility | 2,686 children, 119 deaths (4.4%), so accuracy is useless. Blantyre motor "no response" gives 44% mortality |
| P2 | [Feature engineering](P2_feature_engineering.ipynb) | Leakage removal, cleaning, **WHO z-scores (LMS)**, Blantyre Coma Score, age-adjusted vitals, missingness flags | SAM doubles mortality (7.9% vs 3.8%); BCS ≤ 2 gives 28% mortality |
| P3 | [Baseline model](P3_baseline_model.ipynb) | EPV, scikit-learn `Pipeline`, repeated CV, bedside score comparator, odds ratios, overfitting | Logistic AUROC 0.75 vs bedside danger-sign score 0.72; the 336-feature model overfits (train 0.96 / CV 0.66) |
| P4 | [Calibration & thresholds](P4_calibration_threshold.ipynb) | Calibration, why **not** to rebalance classes, threshold at FPR ≤ 20%, PPV/NNE, **decision curve analysis** | Well calibrated (O/E 1.00). Class weights leave AUROC unchanged but predict 39% risk vs 4.4% observed |
| P5 | [Boosting & SHAP](P5_boosting_shap.ipynb) | Gradient boosting vs logistic regression, **bootstrap CIs**, exact SHAP from scratch, auditing explanations | No gain from boosting (Δ AUROC −0.004, 95% CI −0.04 to +0.04). SHAP reveals a U-shaped respiratory-rate effect and implausible learned effects |
| P6 | [Synthetic data, fairness, transportability](P6_synthetic_fairness_transport.ipynb) | CART synthesis, utility (TSTR) vs privacy (DCR), subgroup performance, prevalence/practice/case-mix shift, recalibration, **TRIPOD+AI** | 100% copied rows can still look "useful". HIV+ false-positive rate 0.67 at one threshold. A one-number intercept update fixes prevalence shift |

Each notebook explains the *why* before each code cell ("What to look for") and ends with **"Try it yourself"** exercises. `scripts/` contains plain-Python versions of each lesson.

## Getting started

Requires **Python 3.12** (tested on 3.12.10).

```bash
git clone https://github.com/drjaber2000/peds-sepsis-ai.git
cd peds-sepsis-ai
python -m venv .venv
.venv\Scripts\activate            # Windows  (macOS/Linux: source .venv/bin/activate)
pip install -r requirements.txt
python get_data.py                # downloads the data (~4 MB) and checks checksums
```

Then open the notebooks in VS Code or Jupyter and run them **in order**: P2 writes `p2_features.csv`, which P3–P6 read. To run a script instead, use for example `python scripts/p2_features.py` from the repository root.
